# 🛒 E-Commerce Sales Analysis & Advanced Data Visualization

## 📌 Project Overview

This project focuses on analyzing E-Commerce sales data using Python. It uses data cleaning, exploratory data analysis (EDA), and advanced data visualization techniques to identify sales trends, top-selling products, and country-wise revenue.

## 🎯 Objectives

* Analyze E-Commerce sales data.
* Clean and preprocess raw data.
* Identify monthly sales trends.
* Find the top 10 products.
* Analyze country-wise revenue.
* Visualize important business insights using Python.

## 📊 Visualizations

### 1. Monthly Sales Trend

Shows how revenue changes over different months.

### 2. Top 10 Products

Identifies the products with the highest sales quantities.

### 3. Country-wise Revenue

Compares revenue generated by different countries.

### 4. Revenue Distribution

Displays the distribution of transaction revenue.

### 5. Correlation Heatmap

Shows relationships between numerical variables.

## 🔍 Key Findings

* The United Kingdom contributes the highest revenue.
* November 2011 shows the highest monthly revenue in the analyzed data.
* PAPER CRAFT, LITTLE BIRDIE is among the leading products by quantity.
* Quantity and revenue show a strong positive correlation.

## ⚙️ Installation & Setup

Clone this repository:

```bash
git clone https://github.com/mohammedrahimuddin/Week2-Advanced-Data-Visualization.git
```

Open the project folder:

```bash
cd Week2-Advanced-Data-Visualization
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

**Dataset Note:** The original and cleaned datasets are not included in this repository because of their file size. Place the UCI Online Retail dataset files inside the `data/` folder before running the notebook.
